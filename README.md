# Estudos em Java

Este repositório reúne exercícios, práticas e desafios desenvolvidos durante as aulas do **Bootcamp Java + IA**, realizado pela **SoulCode Academy em parceria com o PagBank**.

O projeto acompanha minha evolução no aprendizado de Java, partindo dos fundamentos da linguagem até a construção de códigos mais estruturados e a aplicação de conceitos de programação orientada a objetos.

## Conteúdos praticados

Durante as aulas e exercícios, estão sendo trabalhados conceitos como:

- Sintaxe e estrutura básica do Java
- Variáveis e tipos de dados
- Entrada e saída de dados com Scanner
- Operadores e estruturas condicionais
- Estruturas de repetição (`for`, `while` e `for each`)
- Arrays
- ArrayList e List
- HashSet e HashMap
- Métodos e parâmetros
- Classes e objetos
- Getters e Setters
- Tratamento de exceções com `try/catch`
- Formatação de saída

## Organização

Os códigos são adicionados conforme o avanço das aulas e incluem exercícios de fixação, desafios propostos durante o bootcamp e exemplos utilizados para compreender os conceitos estudados.

O repositório também funciona como registro da minha evolução com Java, permitindo revisitar conceitos e acompanhar o desenvolvimento das minhas habilidades ao longo da formação.

## Tecnologias

- Java
- IntelliJ IDEA
- Git
- GitHub

Este é um projeto de estudos contínuo e será atualizado conforme novos conteúdos forem abordados durante o bootcamp.
